How to use Ghost Race
  1. Load two runs of the same map, e.g. your PB as Run A and the world record as Run B.
  2. Line up the starts. Use Move this run only to find the moment each round begins, then press Set start. From then on, both play together.
  3. Line up the screens. Use the ghost size and move sliders so the two maps overlap as closely as possible.
  4. Play it in slow-mo and watch where the ghost bean pulls ahead.
  5. Set both finishes to see the exact gap in seconds and frames.
Tip: it looks best when both players take a similar route. Keyboard: Space = play/pause, ← → = step, R = restart.
